# 留声 · 扩展能力边界 v1

这是给扩展开发者看的“能改什么、不能改什么”。协议版本：`music-connector/1`。

## 能力矩阵

| 能力 | 状态 | 说明 |
|---|---|---|
| 扩展安装 / 启用 / 禁用 | 稳定 | 独立版本目录，失败可回退 |
| 健康检查 | 稳定 | 启动扩展执行 `describe`，不通过不启用 |
| 安全模式 | 稳定 | 禁用所有外部扩展，客户端核心照常启动 |
| Agent 开发工作区 | 稳定 | 自动带入 SDK、示例和测试器 |
| `source.search` | 稳定 | 已并入客户端搜索页，结果带 `extensionId` |
| `source.resolve` | 稳定 | 已接入本地下载任务，返回受控文件路径 |
| `lyrics` / `cover` / `metadata` | 预留 | manifest 可声明，运行时还没接线 |
| UI 主题 / 皮肤 | 不支持 | 主题属于客户端核心 |
| 修改主界面 / 数据库 | 不支持 | 扩展不能改客户端源码或直接写档案库 |
| 任意文件系统访问 | 不支持 | 不得读写音乐库、配置或用户文件 |
| 绕过登录 / DRM | 不支持 | 扩展只能走平台授权和客户端提供的凭据 |

## 扩展类型

- `source`：音源连接器（搜索与本地下载已接入）
- `metadata`：元数据提供者（预留）
- `lyrics`：歌词提供者（预留）
- `cover`：封面提供者（预留）

## 权限声明

manifest 里可以声明：

- `network`：需要访问平台网络
- `auth`：需要平台认证
- `cache`：使用自己的缓存目录

客户端会展示权限，但不会让扩展获得任意文件或数据库访问权。
凭据必须从本机配置或环境变量读取，不能写进 manifest、日志或错误消息。

## 版本与兼容

- 协议主版本：`music-connector/1`
- manifest 变更保持向后兼容；破坏性变更升主版本
- 扩展按 `<id>/<version>/` 安装，active 与 last-good 分离
- 回退只切换版本指针，不重新下载

## 一句话

扩展可以增加**新的音乐来源和可选的元数据能力**；不能改变客户端本身，也不能绕过平台授权。
