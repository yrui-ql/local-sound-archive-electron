开发一个扩展SDK、示例与测试器music-extension-dev
  1. 读协议看 manifest、JSON-RPC 方法和返回结构。协议和示例都在本机，不联网。
  2. 写连接器实现 describe / health / search / resolve；凭据从本机配置读取。
  3. 跑测试用测试器启动连接器，检查 describe、health 和 search 返回。
  4. 安装与回退从文件夹安装；健康检查通过才启用，旧版本随时可回退。

Skill：extension-sdk/SKILL.md；测试：node extension-sdk/test-connector.mjs <目录>
